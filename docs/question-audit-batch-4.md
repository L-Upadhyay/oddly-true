# Question review, batch 4: first five

Five plant drafts were promoted after checking the answer against a botanical, university or research source. Each answer choice was rewritten so the false claims relate to the plant rather than being random impossibilities. The five bundled photographs were visually checked; their individual author, source page and license appear with each revealed fact.
